# MalteBaader.github.io

My personal website, live at **https://www.maltebaader.com** (also https://maltebaader.github.io).

Plain HTML/CSS/JS, with no build step. Each section has its own page (`index.html` for the intro and selected work, then `research.html`, `tools.html`, `teaching.html`, `cv.html`); the menu and footer are repeated in each, so change them everywhere. Edit and push to `main`, and GitHub Pages redeploys automatically.

To update the CV, replace `cv.pdf` with the new file (keep the name) and push.

Preview locally: open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.
